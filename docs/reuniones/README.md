# Reuniones de seguimiento

Crear un archivo `AAAA-MM-DD.md` a partir de `plantilla.md` después de cada reunión. El objetivo es recordar decisiones y comprobar correcciones sin depender de la memoria de una conversación.

Registrar observaciones, decisiones, dudas y tareas por separado. Conservar la ubicación de los archivos originales en el registro local; no publicar grabaciones ni enlaces privados automáticamente. Una tarea se cierra al poder señalar el cambio y su comprobación.

Los criterios repetibles se mantienen en [criterios_profesor.md](../criterios_profesor.md); el estado de implementación está en [correcciones.md](../correcciones.md).
