# Material histórico

Los scripts de esta carpeta corresponden al diseño anterior y se conservan para trazabilidad. No forman parte de la interfaz actual. Algunos ejecutan descargas o escrituras al ejecutarse o importarse.

Sus etiquetas de bloqueo, selección de entradas y manejo de errores no cumplen las reglas del diseño corregido. La base `resultados.db` de la raíz también es histórica y permanece intacta; no se migra ni se sobrescribe con las mediciones nuevas.

Usar la interfaz `pdns-lab` documentada en el README principal.
